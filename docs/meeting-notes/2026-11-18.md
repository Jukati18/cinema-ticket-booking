Nhận diện các module chức năng

| Module | Chức năng |
| :---- | :---- |
| Movie | Phim, rạp, suất chiếu, tìm kiếu, lọc theo danh mục |
| Seat & booking | Sơ đồ ghế, giữ ghế, đặt vé, hủy vé |
| Authentication | Đăng ký, đăng nhập, xác thực email, phân quyền  |
| Payment | Thanh toán, xác thực, |
| Cinema Management | Quản lý rạp, phòng, combo, giá |
| Operation | Vận hành suất chiếu |
| Reporting | Báo cáo doanh thu, thể loại yêu thích, tỉ lệ lấp đầy |
| Notification | Email |

Luồng nghiệp vụ:  
Tình huống: 1 khách vãng lai vào mua 2 vé xem phim  
Tìm kiếm phim → chọn chi nhánh → chọn suất chiếu → chọn từng ghế → bắp nước (option) → bấm thanh toán (hệ thống giữ chỗ 5p) → thanh toán thành công → 

Tình huống hay: bạn A đã chọn ghế → timer (x phút) (bắp nước → điền thông tin → kiểm tra thông tin → thanh toán) → gửi mã qr về email 

Tuần này: 

- Chốt quy tắc giao tiếp giữa backend và frontend (m gửi gì, t nhận gì) → ví dụ bằng người dùng đặt vé  
- Làm use case (kèm database) và user story  
- Thiết kế cơ sở dữ liệu cho hệ thống
